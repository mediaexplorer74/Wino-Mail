# 🚀 Добро пожаловать в Wino Mail 1.9.1-альфа-версию

Наконец-то готов еще один крупный релиз для Wino Mail! Этот релиз содержит фундаментальные изменения в архитектуре Wino. Поэтому, к сожалению, вам придется повторно добавить свои учетные записи.

И снова, в этом выпуске много улучшений. Обязательно ознакомьтесь со всеми из них и дайте нам знать о ваших отзывах!

## Улучшена фоновая синхронизация и системный трей

Фоновая синхронизация полностью переработана. Вся синхронизация будет выполнена с помощью этого процесса. Двойной щелчок по иконке в трее запустит само приложение. Ваши учетные записи будут синхронизироваться каждые 3 минуты.

Убедитесь, что включена функция "Сворачивать запуск при запуске Windows", а для параметра "Поведение при закрытии приложения" установлено значение "Сворачивать в системный трей" или "Запускать в фоновом режиме", чтобы продолжать получать уведомления. 

![Системный трей](https://www.winomail.app/patchNotes/190/backgroundsync2.png)

Wino продолжает работать в системном трее даже после закрытия страницы. При закрытии Wino она не закроется полностью, но в системном трее будет запущен небольшой отдельный процесс. Вы можете настроить это поведение на странице, описанной выше.

![Системный трей](https://www.winomail.app/patchNotes/190/backgroundsync1.png)

## Псевдонимы электронной почты 

Поддержка псевдонимов доступна здесь! Учетные записи Gmail будут автоматически синхронизировать псевдонимы. Outlook пока не будет синхронизировать их автоматически из-за ограничений со стороны Microsoft, но вы можете зарегистрировать их вручную в настройках учетной записи. 

Пожалуйста, обратите внимание, что ваши учетные записи являются локальными только для Wino Mail, а это означает, что если ваш провайдер не разрешает отправлять электронные письма под псевдонимом, ваши письма не будут доставлены. Пожалуйста, добавляйте только те псевдонимы, на которые у вашего почтового провайдера есть разрешение отправлять электронные письма.

Что касается IMAP, убедитесь, что ваш SMTP-сервер также позволяет отправлять электронные письма с зарегистрированных псевдонимов.

![Настройки псевдонимов](https://www.winomail.app/patchNotes/190/alias1.png)

Ваш основной адрес электронной почты всегда будет подтвержден после добавления учетной записи и будет помечен как основной. Вы можете изменить свой основной псевдоним на этой странице, чтобы изменить псевдоним по умолчанию для черновиков писем.

![Управление псевдонимами](https://www.winomail.app/patchNotes/190/alias2.png)

Чтобы выбрать учетную запись для отправки писем, воспользуйтесь средством выбора в composer.

![Псевдоним для выбора](https://www.winomail.app/patchNotes/190/alias3.png)

## Аватары отправителей

Wino Mail теперь синхронизирует изображение вашей учетной записи в Outlook и Gmail! Это основа для поддержки другого компонента Wino "Контакты Wino" для управления контактами. К сожалению, в Wino Mail пока нет системы управления контактами, но она у меня есть в качестве отдельного приложения на будущее.

![Выбор псевдонима](https://www.winomail.app/patchNotes/190/avatars1.png)

## Улучшения пользовательского интерфейса

### Разделитель списка рассылки (от [Tiktack](https://github.com/Tiktack))

Теперь вы можете регулировать ширину списка рассылки, перетаскивая разделитель между сообщениями и отображаемым контентом. Автор: @TikTack

### Удалена панель инструментов действий (с помощью [Tiktack](https://github.com/Tiktack))

Мы убрали элементы панели инструментов в верхней части списка рассылки по умолчанию, чтобы сэкономить место для пользователей настольных компьютеров. 

![Панель инструментов](https://www.winomail.app/patchNotes/190/ui1.png)

Вы все еще можете включить их в меню Настройки -> Список рассылки. В основном им пользовались пользователи планшетов.

![Включить панель инструментов](https://www.winomail.app/patchNotes/190/ui2.png)

### Новый вид темы беседы

Темы беседы теперь больше похожи на почту и календари. Также исправлена пара проблем с наведением курсора мыши, которые были вызваны старым элементом управления.

![Темы](https://www.winomail.app/patchNotes/190/ui3.png)

## Исправления ошибок

Как всегда, в этом крупном выпуске исправлено множество общих ошибок для приложения. Я перечисляю некоторые из наиболее важных здесь:

* @Tiktack Улучшил обработку ссылок mailto в https://github.com/bkaankose/Wino-Mail/pull/310
* Встроенные изображения заменены ресурсами, связанными с cid.  с помощью @Tiktack в https://github.com/bkaankose/Wino-Mail/pull/313
* Исправлены настройки подписи учетной записи при создании черновика с помощью @Tiktack в https://github.com/bkaankose/Wino-Mail/pull/314
* Исправлена ошибка, из-за которой при повторном открытии черновика сообщения с вложением содержимое вложения изменялось.
* Исправлена ошибка, из-за которой страница создания не размещалась должным образом при выходе со страницы, в результате чего черновики не обновлялись.
* Исправлен обмен журналами @bkaankose в https://github.com/bkaankose/Wino-Mail/pull/328
* Заставьте Jodit заполнить всю доступную высоту webview с помощью @Tiktack в https://github.com/bkaankose/Wino-Mail/pull/330
* Качество кода: панель команд с вкладками с помощью @Tiktack в https://github.com/bkaankose/Wino-Mail/pull/335
* Включены журналы протоколов для активного использования для всех учетных записей imap. Если у вас возникнут какие-либо ошибки сервера для учетных записей imap, они будут записываться вместе с журналами приложений для диагностики проблем. При совместном использовании журналов протоколов также автоматически будут доступны журналы протоколов. ** В журналах протоколов не будут предоставлены учетные данные или конфиденциальная информация.**
* Исправлена проблема с загрузкой папок, из-за которой письма, принадлежащие к другой папке, иногда отображались в папке с последним нажатием.
* Исправлена проблема с переупорядочением учетных записей, из-за которой при перемещении объединенных учетных записей всегда оказывались последними, независимо от установленного порядка.
* Исправлена ошибка, из-за которой прогресс синхронизации учетной записи отображался в первой учетной записи, а не в синхронизированной учетной записи для объединенных учетных записей.
* Исправлена ошибка пользовательского интерфейса, из-за которой несколько элементов to, cc, bcc неправильно отображались в небольших макетах. Теперь они будут обернуты и выровнены в соответствии с размером экрана.
* Исправлена возможная ошибка для устройств, которые не поддерживают опцию закрепления на панели задач.
* Исправлена ошибка, из-за которой при применении настройки папок папки не загружались повторно, если настройка была выполнена для выбранной учетной записи.
* Улучшена фокусировка редактора на странице composer. При перемещении фокуса из поля "Тема" первая строка редактора теперь фокусируется правильно. Щелчок по редактору также приводит к тому же результату.
* Исправлена проблема с удалением писем из папки "Отправленные" в Gmail.
* Исправлены проблемы с отправкой сообщений Outlook из-за размеров заголовков MIME.
